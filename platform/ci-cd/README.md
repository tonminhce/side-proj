# platform/ci-cd

CI/CD planning, runbooks, and policy home.

> **Note on GitHub Actions path semantics:** The actual workflow file lives at
> the repository root at `.github/workflows/ci.yml`. GitHub only honors that
> path; `platform/ci-cd/.github/workflows/ci.yml` (referenced by
> `architecture.md` line 822) is not executable. See
> `.github/workflows/README.md` for the rationale. This directory remains the
> documentation home for CI/CD planning.
